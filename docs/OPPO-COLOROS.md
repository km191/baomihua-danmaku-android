# OPPO / ColorOS 适配说明

这份文档对应安卓版 **1.2.0 及以后**（当前 1.35）。适用于：

- OPPO 手机（ColorOS 12 / 13 / 14 / 15）
- 一加手机（ColorOS 系统）
- realme 手机（realme UI 3.0 及以上，底层同为 ColorOS）
- 其他把「自启动 / 耗电管理 / 悬浮窗」拆成独立权限的国产 ROM（按同样思路设置）

Android 原生、小米、vivo 等机型不需要看这份文档，应用里的通用权限卡已经够用；
ColorOS 专用卡片只会在识别到 OPPO / 一加 / realme 时出现。

---

## 一、为什么 OPPO 要单独适配

ColorOS 和原生 Android 有三处不一样，都会直接影响弹幕：

| 差异 | 后果 | 本版怎么处理 |
|---|---|---|
| 后台管控严（应用速冻、智能省电、锁屏清理） | 弹幕看一会儿突然没了，通知栏的前台服务也被清掉 | 前台服务 + 常驻通知 + 划掉任务后 2 秒闹钟恢复 + 15 分钟看护任务 + 电池白名单引导 |
| 权限入口分散且版本间改包名 | 用户找不到「自启动」「耗电管理」在哪 | 面板里的「ColorOS 后台设置」卡片，按 `com.oplus.*` → `com.coloros.*` → 应用详情页逐级兜底 |
| 挖孔屏 + 全面屏手势条 | 第一行弹幕画进摄像头，或最后一行压在手势条下面 | 悬浮窗按 `WindowMetrics` 的安全区排版，百分比只作用于安全区；横屏侧边导航也避开 |

另外，ColorOS 的「智能侧边栏」和手势返回都从屏幕边缘识别，所以悬浮球默认离屏幕边缘 14dp，
拖动后也会记住位置，不会被手势区吃掉。

## 二、首次使用（按这个顺序）

1. **安装 APK**：`dist/DanmuCompanion-1.2.0.apk`。允许「安装未知来源应用」。
2. **打开应用**，按「还差几步」卡片逐个授权：
   - 悬浮窗权限
   - 通知使用权
   - 通知权限（Android 13+）
   - 后台运行（ColorOS）
3. 回到面板点 **开启悬浮窗**。屏幕上会出现一条「悬浮窗已开启」的提示和橙色「弹」字球。
4. 第一次开启时如果电池优化还没放行，会弹一个 **「ColorOS 还要放行两步」** 的提示，
   点「去放行」直接跳到系统页面。
5. 在任意播放器里播放视频，几秒后弹幕出现。

> **Android 13+ 安装提示**：从浏览器或文件管理器安装的 APK 属于「非应用商店安装」，
> 系统可能把「通知使用权」开关置灰。到 **应用信息 → 右上角「⋮」→ 允许受限设置**，
> 再回系统设置里打开「通知使用权」。ColorOS 14/15 上这一步偶尔会出现。

> 如果第 4 步点了「稍后」，之后还可以在面板的 **「ColorOS 后台设置」** 卡片里补上。

## 三、ColorOS 设置路径（按版本略有不同）

面板里的按钮会尽量直达；如果系统页面改版、按钮跳到了应用详情页，就按下面的路径手动找。
「ColorOS 后台设置」卡片在「自检」下面。

### ColorOS 14 / 15

| 权限 | 路径 |
|---|---|
| 悬浮窗 | 设置 → 应用管理 → 弹幕伴侣 → 权限管理 → 悬浮窗 |
| 自启动 | 设置 → 应用管理 → 弹幕伴侣 → 自启动 |
| 耗电管理 | 设置 → 电池 → 应用耗电管理 → 弹幕伴侣 → 允许后台活动 |
| 后台弹出界面 | 设置 → 应用管理 → 弹幕伴侣 → 权限管理 → 后台弹出界面 |
| 通知使用权 | 设置 → 通知与状态栏 → 通知使用权 → 「弹幕伴侣 · 媒体识别」 |
| 电池优化 | 设置 → 电池 → 更多设置 → 电池优化 → 弹幕伴侣 → 不优化 |

### ColorOS 12 / 13

| 权限 | 路径 |
|---|---|
| 悬浮窗 | 设置 → 应用管理 → 弹幕伴侣 → 权限管理 → 悬浮窗 |
| 自启动 | 设置 → 应用管理 → 自启动管理 → 弹幕伴侣 |
| 耗电管理 | 设置 → 电池 → 应用耗电管理 → 弹幕伴侣 → 允许后台活动 |
| 后台弹出界面 | 设置 → 应用管理 → 弹幕伴侣 → 权限管理 → 后台弹出界面 |
| 通知使用权 | 设置 → 通知与状态栏 → 通知使用权 |

### realme UI

路径与 ColorOS 基本一致，个别版本把「耗电管理」放在
**设置 → 电池 → 更多设置 → 睡眠待机优化**，把弹幕伴侣设为「不优化」即可。

### 一加（ColorOS）

与 ColorOS 相同；氧OS（OxygenOS）国际版如果找不到「自启动」，至少把
**电池 → 电池优化 → 弹幕伴侣 → 不优化** 打开。

## 四、三项建议全开

| 设置 | 建议值 | 不开会怎样 |
|---|---|---|
| 电池优化 | 不优化 / 允许后台活动 | 锁屏几分钟后服务被冻结，弹幕消失；解锁后看护任务最多 15 分钟才拉回 |
| 自启动 | 允许 | 重启手机后不会自动恢复（打开应用仍可手动恢复） |
| 后台弹出界面 | 允许 | 点悬浮球弹小面板时，ColorOS 可能拦下窗口，表现为「点了没反应」 |

悬浮窗权限和通知使用权是**必须**的，缺一个就没有弹幕或读不到播放进度。

## 五、这一版在 OPPO 上具体做了什么

### 1. 安全区排版

- 用 `WindowMetrics.getWindowInsets()` 读取状态栏、导航栏、挖孔的安全区。
- `regionTopPercent / regionBottomPercent` 只作用于「安全区」，不再按整块屏幕算。
- 横屏时侧边导航栏的 inset 也会让悬浮窗左右收窄。
- 拿不到 insets 的老系统退回 `status_bar_height` / `navigation_bar_height` 资源值。

### 2. 后台保活（不常驻轮询）

| 机制 | 触发时机 | 作用 |
|---|---|---|
| 前台服务 + 常驻通知 | 开启悬浮窗 | 正常情况下的主体，系统知道它在干活 |
| `onTaskRemoved` 闹钟 | 从最近任务划掉 | 2 秒后尝试重新拉起 |
| `onDestroy` 兜底闹钟 | 服务被系统销毁 | 3 秒后尝试重新拉起 |
| 15 分钟 JobScheduler | 持久化任务 | 被「应用速冻」后，解冻时补拉一次 |
| 电池白名单 | 用户放行 | 从系统层面减少冻结 |

以上恢复都会先检查三件事：**用户还开着悬浮窗、悬浮窗权限还在、服务确实没在跑**，
不会出现「用户已经关掉又被拉起来」的情况。

### 3. 权限页直达

`OemSettings` 里的候选顺序：

- 自启动：`com.oplus.safecenter` → `com.coloros.safecenter` → `com.oppo.safe` → 应用详情页
- 耗电管理：`com.oplus.battery` → `com.coloros.oppoguardelf` → 系统电池优化页 → 应用详情页
- 每次跳转都会写进「自检 → 最近事件」，跳转失败也不会崩。

### 4. 诊断信息

「自检」卡片新增：

- **机型**：`OPPO PJD110` 这样的厂商 + 型号
- **系统**：`ColorOS 14.0.1 · Android 14`（版本号能从 Build 字段里读到时）
- **屏幕**：分辨率 + 安全区上下值

「复制诊断」会带上这些信息，反馈问题时不用再手打机型。

## 六、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 开启后什么都没出现 | 看「自检 → 弹幕窗」是否「已挂载」。再点「测试横幅」回桌面，应看到橙色「悬浮窗在这 ✓」。看不到就是悬浮窗权限被系统拦了，去「权限管理 → 悬浮窗」重新允许 |
| 弹幕出现几分钟后消失 | 电池优化没放行。到「ColorOS 后台设置 → 电池优化」放行；锁屏场景还要确认「耗电管理 → 允许后台活动」 |
| 从最近任务划掉后，过一会儿又出现悬浮球 | 这是有意的自动恢复。不想恢复就在面板里关掉悬浮窗，或到系统设置里强行停止应用 |
| 重启手机后没有自动恢复 | 检查「自启动」是否允许；没允许时打开一次应用也会自动恢复（上次开着的话） |
| 点悬浮球没反应 | 检查「后台弹出界面」权限；部分 ColorOS 版本还需要「锁屏显示」 |
| 通知栏点一下没反应 | ColorOS 可能把长通知折叠了；展开通知后点「隐藏悬浮窗 / 显示悬浮窗」动作，或直接点通知本体 |
| 通知使用权里找不到本应用 / 开关是灰的 | Android 13+ 的「受限设置」；到 应用信息 → 右上角「⋮」→ 允许受限设置，再回去授权 |
| 第一行弹幕被摄像头挡住 | 1.2.0 已按挖孔安全区排版；如果仍然挡住，把「弹幕行数」调小，或在系统里把前置摄像头挖孔区域设为隐藏 |
| 横屏时右侧弹幕被导航栏切掉 | 1.2.0 已按侧边 inset 收窄；三键导航用户可临时切手势导航对比 |
| 悬浮球拖到屏幕边缘后不好拖 | 悬浮球默认离边 14dp；拖到边缘会自动记住，下次仍在这个位置 |
| 弹幕比画面早/晚 | 面板「校准」输入画面当前时间，或用「时间偏移」微调（正数让弹幕晚出现） |
| 小面板打开后播放器暂停了 | 小面板是悬浮窗，不会切走播放器；如果播放器自身在失焦时暂停，属于播放器行为，可在播放器设置里关闭「失焦暂停」 |

## 七、卸载与清理

1. 先在面板里 **关闭悬浮窗**（会同时取消闹钟和看护任务）。
2. 设置 → 应用管理 → 弹幕伴侣 → 卸载。
3. 如果之前开启过「自启动」，卸载后系统里的自启动记录会自动消失。

个人设置、弹幕缓存都在应用私有目录，卸载即清除，不会留在相册或下载目录。

## 八、给开发者的验证清单

没有 OPPO 真机时，至少做这些静态检查：

```powershell
# 1. 构建
powershell -ExecutionPolicy Bypass -File scripts/build.ps1

# 2. 核心测试（含 ColorOS 识别、安全区计算）
powershell -ExecutionPolicy Bypass -File scripts/test.ps1
```

测试里覆盖了：

- `OemProfile`：OPPO / 一加 / realme / OPLUS / 小米 / 空值识别，ColorOS 版本号提取。
- `RegionMath`：1080×2412 挖孔屏、1920×1080 无安全区、安全区超过屏高 1/4 的夹紧、最小高度兜底。

真机上建议按这个顺序过一遍：

1. 首次安装 → 三/四个权限 → 开启悬浮窗 → 桌面看到测试横幅。
2. 打开视频播放器 → 识别片名 → 弹幕出现。
3. 锁屏 3 分钟 → 解锁 → 弹幕应还在（电池优化已放行的情况下）。
4. 从最近任务划掉 → 2~5 秒内悬浮球应回来。
5. 横竖屏切换 → 弹幕区域重算，不压挖孔/手势条。
6. 重启手机（自启动已允许）→ 悬浮球自动回来。
